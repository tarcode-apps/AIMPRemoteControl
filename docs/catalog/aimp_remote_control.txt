Description:
Удалённое управление AIMP по локальной сети: из браузера на мобильном, планшете или другом компьютере или из приложения «AIMP Remote Control» для Android. Windows и Linux.
- Плейлисты с группами, обложками и рейтингами, поиск по плейлисту или по всем плейлистам, сортировка и перестановка треков.
- Управление воспроизведением, синхронизированные тексты песен, сведения о треке, запись радио.
- Очередь, таймер сна, звуковые эффекты и 20-полосный эквалайзер с пресетами, избранное.
- Добавление файлов с компьютера и потоков, загрузка файлов и целых папок перетаскиванием, скачивание треков.
- Авторизация, права клиента и список сетевых интерфейсов настраиваются в плеере.
Приложение «AIMP Remote Control» больше не поддерживается, но работает с плагином без изменений; APK — в теме на 4PDA: https://4pda.to/forum/index.php?showtopic=499539
Исходный код на GitHub: https://github.com/tarcode-apps/AIMPRemoteControl

Description (English):
Remote control of AIMP over the local network: from a browser on a mobile, a tablet or another computer, or from the "AIMP Remote Control" Android app. Windows and Linux.
- Playlists with groups, covers and ratings, search in a playlist or across all of them, sorting and reordering tracks.
- Playback control, synced lyrics, track information, radio capture.
- Queue, sleep timer, sound effects and the 20-band equalizer with presets, favorites.
- Adding files of the computer and streams, uploading files and whole folders by drag and drop, downloading tracks.
- Authentication, client permissions and the list of network interfaces are configured in the player.
The "AIMP Remote Control" app is no longer maintained but works with the plugin unchanged; the APK is in the 4PDA thread: https://4pda.to/forum/index.php?showtopic=499539
Source code on GitHub: https://github.com/tarcode-apps/AIMPRemoteControl
