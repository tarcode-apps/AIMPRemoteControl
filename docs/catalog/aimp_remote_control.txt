Description (English):
An alternative remote control server for AIMP over the local network — for the "AIMP Remote Control" Android app. Windows and Linux.
- Playlists and playback queue, playback control, 18-band equalizer.
- Covers, lyrics, ratings, search.
- Browsing the computer's files, adding files and streams, uploading and downloading tracks, sleep timer.
- Authentication, client permissions and the list of network interfaces are configured in the player.
The app: https://aimpremote.blogspot.com — the APK is in the 4PDA thread: https://4pda.to/forum/index.php?showtopic=499539
Source code on GitHub: https://github.com/tarcode-apps/AIMPRemoteControl
