AIMP Remote Control - удалённое управление плеером по сети [AIMP5]

--- ТЕКСТ СООБЩЕНИЯ ----------------------------------------------------------

[b]Название:[/b] AIMP Remote Control
[b]Версия:[/b] {VERSION}
[b]Автор:[/b] Artem Tarasov

[b]Описание[/b]

Удалённое управление AIMP по локальной сети: из браузера на мобильном, планшете или другом компьютере - достаточно открыть адрес плеера - или из приложения [b]AIMP Remote Control[/b] для Android, которое работает с плагином без каких-либо изменений и настроек.

Возможности:
[list]
[li]все плейлисты плеера с группами, обложками и рейтингами; создание, переименование и удаление плейлистов, сортировка и перестановка треков;[/li]
[li]поиск по плейлисту и по всем плейлистам сразу: по названию, исполнителю, альбому, жанру или файлу;[/li]
[li]управление воспроизведением: пуск/пауза/стоп, следующий и предыдущий трек, перемотка, громкость, повтор и перемешивание;[/li]
[li]синхронизированные тексты песен, сведения о треке, запись радио;[/li]
[li]очередь воспроизведения: перестановка, удаление, приостановка;[/li]
[li]звуковые эффекты и 20-полосный эквалайзер с пресетами;[/li]
[li]таймер сна: через заданное время, в заданное время, после нескольких треков, в конце плейлиста или очереди;[/li]
[li]избранное;[/li]
[li]добавление файлов с компьютера и интернет-потоков, загрузка файлов и целых папок перетаскиванием на плейлист, скачивание треков;[/li]
[li]в браузере - раскладки для мобильного и для широкого экрана, светлая и тёмная тема, русский и английский языки.[/li]
[/list]
Приложение умеет то же, что умело всегда: плейлисты и очередь, воспроизведение, эквалайзер, обложки, тексты песен, обзор файлов, загрузку и скачивание треков, таймер. Всё новое появляется в браузере.

[b]Настройка[/b]

Настройки -> Плагины -> [i]Удалённое управление[/i]:
[list]
[li][b]Подключение[/b] - список адресов, на которых работает сервер. Откройте один из них в браузере (http://<адрес>:3333/) или введите в приложении - оно умеет и само найти плеер в сети. Снимите галочку с интерфейса, чтобы не слушать на нём: на исключённом интерфейсе порт не открывается вообще.[/li]
[li][b]Разрешения клиента[/b] - что браузеру и приложению позволено помимо управления воспроизведением: обзор файлов на компьютере, удаление треков с диска, скачивание и загрузка треков, функции таймера. Всё выключено по умолчанию, кроме скачивания треков.[/li]
[li][b]Требовать авторизацию[/b] - имя пользователя и пароль (HTTP Digest) для всех клиентов; браузер спросит их один раз. Рекомендуется в любой сети, которой вы не доверяете полностью: без авторизации управлять плеером может любой, кто находится в этой сети.[/li]
[/list]
Порты: TCP 3333 (управление из браузера и из приложения), UDP 3332 (поиск плеера приложением). Разрешите AIMP принимать подключения по ним в брандмауэре.

[b]Приложение[/b]

Приложение [b]AIMP Remote Control[/b] постепенно уходит в прошлое: оно больше не поддерживается, удалено из Google Play, и на [url=https://aimpremote.blogspot.com]сайте приложения[/url] нет APK; на практике его можно найти в [url=https://4pda.to/forum/index.php?showtopic=499539]теме на 4PDA[/url]. Плагин по-прежнему работает с последней выпущенной версией приложения - 2.0.31.

Плагин не связан с авторами AIMP и авторами приложения.

[b]Установка[/b]

Откройте [b]aimp_remote_control.aimppack[/b] плеером: двойной клик или перетащите файл на окно AIMP. Если по двойному клику файл не открывается, откройте [i]Настройки -> Плагины[/i] и нажмите [i]установить[/i].

После установки включите плагин там же, в [i]Настройки -> Плагины[/i], и откройте в браузере один из адресов со страницы его настроек.
