AIMP Remote Control - удалённое управление плеером по сети [AIMP5]

--- ТЕКСТ СООБЩЕНИЯ ----------------------------------------------------------

[b]Название:[/b] AIMP Remote Control
[b]Версия:[/b] 1.3.0
[b]Автор:[/b] Artem Tarasov
[b]Лицензия:[/b] MIT

[b]Платформы:[/b] Windows 32/64-бит, Linux 64-бит

[hr]

[b]Описание[/b]

Альтернативный сервер удалённого управления AIMP по локальной сети. Управлять плеером можно с телефона из приложения [b]AIMP Remote Control[/b] для Android - оно работает с плагином без каких-либо изменений и настроек.

Зачем: приложение больше не поддерживается, а его плагин работает только с 32-битными версиями AIMP. Этот плагин - открытая замена серверной части.

Умеет всё, что запрашивает приложение:
[list]
[li]плейлисты и очередь воспроизведения: чтение, создание, переименование, удаление, добавление и удаление треков, перестановка очереди;[/li]
[li]управление воспроизведением: пуск/пауза/стоп, следующий и предыдущий трек, громкость, отключение звука, перемотка, повтор и перемешивание;[/li]
[li]18-полосный эквалайзер с предусилением;[/li]
[li]обложки, тексты песен, рейтинги треков;[/li]
[li]поиск по плейлистам;[/li]
[li]обзор файлов на компьютере, добавление файлов и интернет-потоков в плейлист;[/li]
[li]загрузка треков с телефона в плеер и скачивание треков из плеера на телефон;[/li]
[li]таймер сна: пауза, закрытие плеера, выключение, сон и гибернация компьютера;[/li]
[li]обновление состояния плеера в реальном времени (long polling).[/li]
[/list]

[b]Настройка[/b]

Настройки -> Плагины -> [i]Удалённое управление[/i]:
[list]
[li][b]Подключение[/b] - список адресов, на которых работает сервер. Введите один из них в приложении на телефоне или дайте приложению найти плеер в сети самостоятельно. Снимите галочку с интерфейса, чтобы не слушать на нём: на исключённом интерфейсе порт не открывается вообще.[/li]
[li][b]Разрешения клиента[/b] - что приложению позволено помимо управления воспроизведением: обзор файлов на компьютере, удаление треков с диска, загрузка треков, функции таймера. Всё выключено по умолчанию.[/li]
[li][b]Требовать авторизацию[/b] - имя пользователя и пароль (HTTP Digest). Рекомендуется в любой сети, которой вы не доверяете полностью: без авторизации управлять плеером может любой, кто находится в этой сети.[/li]
[/list]
Порты: TCP 3333 (управление), UDP 3332 (поиск плеера в сети). Разрешите AIMP принимать подключения по ним в брандмауэре.

[b]Приложение[/b]

Приложение [b]AIMP Remote Control[/b] больше не поддерживается: оно удалено из Google Play, и официальной ссылки на APK не осталось - на [url=https://aimpremote.blogspot.com]сайте приложения[/url] его нет. На современном Android приложение работает нормально; на практике APK можно найти в [url=https://4pda.to/forum/index.php?showtopic=499539]теме на 4PDA[/url]. Плагин рассчитан на последнюю выпущенную версию приложения - 2.0.31.

Плагин не связан с авторами AIMP и авторами приложения.

[b]Установка[/b]

Откройте [b]aimp_remote_control.aimppack[/b] плеером: двойной клик или перетащите файл на окно AIMP. Если по двойному клику файл не открывается, откройте [i]Настройки -> Плагины[/i] и нажмите [i]установить[/i].

После установки включите плагин там же, в [i]Настройки -> Плагины[/i].
